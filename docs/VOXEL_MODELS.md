# Модели героев для «За гранью» — задание для MagicaVoxel

Эталон стиля: лист «Воин / Маг / Плут / Жрец, мужской и женский» (приложить к заданию).
Цель: 8 фигурок того же уровня, собранных из частей, чтобы редактор внешности
мог менять причёску, наряд и оружие независимо.

## 1. Инструмент и формат

- Редактор: MagicaVoxel (бесплатный, https://ephtracy.github.io).
- Формат: `.vox`, по одному файлу на деталь (список ниже).
- Палитра: одна общая на все файлы, `palette.png` 256 цветов. Сначала делается палитра,
  потом модели. Цвета, которые игрок перекрашивает в редакторе, кладутся в отдельные
  зарезервированные ячейки (раздел 5).
- Без материалов «стекло/металл/свечение» MagicaVoxel: игра их не читает. Свечение
  (кристалл посоха) — только ячейка палитры 250–255.

## 2. Масштаб и сетка

- 1 воксель = 1/20 клетки игрового поля. Клетка поля = 20 × 20 вокселей.
- Рост фигуры с волосами: 28–30 вокселей. Без причёски (только голова): 25.
- Голова: 10 × 10 × 9 (ширина × высота × глубина). Тело с ногами: 15 вокселей.
- Ширина в плечах с наплечниками не больше 16, чтобы фигура помещалась в клетку.
- Ноги стоят на Z = 0. Подставку (круглый постамент) не делать: её рисует игра.
- Лицом к +Y в MagicaVoxel (в игре это «вперёд»).

## 3. Точка отсчёта (обязательно одинаковая во всех файлах)

Размер холста каждого файла: 32 × 32 × 32. Центр фигуры по X и Y — воксель (16, 16).
Тогда все детали совпадают без сдвигов, если их открыть поверх друг друга.

| Точка крепления | Координата (X, Y, Z) | Что крепится |
|---|---|---|
| Центр макушки | (16, 16, 25) | причёски, шлемы, капюшоны |
| Правая кисть, хват | (9, 18, 9) | меч, кинжал, посох, булава |
| Левая кисть, хват | (23, 18, 9) | щит, книга |
| Центр спины | (16, 12, 14) | плащи |

Рука в хвате держит рукоять вертикально, рукоять проходит через точку хвата.
Оружие рисуется так, чтобы его рукоять проходила через ту же точку — тогда оно
не «отлетает» от руки.

## 4. Список файлов

Тело (обязательно 2 файла, без волос, одежды и оружия, в простом нижнем белье):
- `body_male.vox`, `body_female.vox` — голова с глазами и бровями, кисти, ступни.

Лицо делается на теле: глаза 2 × 3 тёмных вокселя с одним бликом, брови 3 × 1,
рот 2 × 1 или без рта. Носа нет.

Причёски (по одному файлу, каждая для обоих полов, без лысых мест при обзоре со всех
сторон — волосы должны полностью закрывать макушку и затылок):
`hair_short`, `hair_buzz`, `hair_spiky`, `hair_mohawk`, `hair_sweep`, `hair_bob`,
`hair_long`, `hair_wavy`, `hair_ponytail`, `hair_bun`, `hair_twin`, `hair_braid`,
`hair_curly`. («Без волос» — просто отсутствие файла.)

Наряды (отдельно для мужского и женского тела, `_m` / `_f`), по 4 на класс:
- воин: `outfit_plate`, `outfit_tabard`, `outfit_leather`, `outfit_knight`;
- маг: `outfit_robe`, `outfit_mantle`, `outfit_sash`, `outfit_scholar`;
- плут: `outfit_leathers`, `outfit_vest`, `outfit_tunic`, `outfit_studded`;
- жрец: `outfit_vestments`, `outfit_surplice`, `outfit_mail`, `outfit_monk`.

Для первой версии достаточно первого наряда каждого класса (8 файлов) — как на листе.

Головные уборы: `hat_hood`, `hat_wizhat`, `hat_helm`, `hat_circlet`, `hat_headband`,
`hat_cap`, `hat_crown`. Капюшон и шлем закрывают верх причёски сами (игра в этот момент
скрывает часть волос — оставьте внутри убора пустое место под голову 10 × 10 × 9).

Плащи: `cape_short`, `cape_long`, `cape_mantle`.

Предметы в руках: `held_sword`, `held_dagger`, `held_shield`, `held_staff_wizard`,
`held_mace_cleric`, `held_bow`, `held_book`.

Бороды (только мужское тело): `beard_stubble`, `beard_mustache`, `beard_goatee`,
`beard_short`, `beard_full`, `beard_long`, `beard_sideburns`.

## 5. Цвета, которые меняет игрок

Эти ячейки палитры игра перекрашивает по выбору в редакторе, поэтому рисуйте ими
нужные места, оттенки — соседними ячейками (светлее/темнее):

| Ячейки | Что |
|---|---|
| 1–3 | кожа: основной, тень, свет |
| 4–6 | волосы и борода |
| 7–9 | основной цвет одежды |
| 10–12 | дополнительный цвет одежды |
| 13–15 | отделка (золото/серебро) |
| 16–18 | кожаные ремни, пояс, сапоги |
| 19–21 | цвет плаща/капюшона |
| 22–24 | глаза |
| 250–255 | свечение (кристаллы, огонь) |

Всё остальное (сталь клинка, дерево древка, крест на щите) — любые другие ячейки.

## 6. Как проверить перед сдачей

1. Открыть `body_male.vox`, затем через «импорт» поверх него причёску, наряд и меч —
   всё должно сесть на место без ручного сдвига.
2. Повернуть модель на 360°: нет дыр в волосах, нет «висящих» предметов.
3. Сравнить рядом с эталонным листом при одинаковом размере.

## 7. Что делает игра (для разработчика)

- Загрузка: `three/examples/jsm/loaders/VOXLoader.js`, по одному мешу на файл, общая
  палитра, перекраска зарезервированных ячеек по внешности героя.
- Сборка героя: тело + причёска + наряд + убор + плащ + борода + предметы, все с
  нулевым смещением (общая точка отсчёта).
- Анимации: тело делится на голову, туловище, руки и ноги по высоте/координатам;
  предметы в руках привязываются к кисти, поэтому двигаются вместе с ней.
- Текущие модели из `src/characters.js` остаются запасным вариантом, пока все файлы
  не готовы. Сохранения героев не меняются: внешность хранится как настройки.
