# Рюкзак: текущая реализация

Обновление 2026-10-19 развивает существующий рюкзак, сохраняя формат сохранений, лимит 20 ячеек, прежние иконки, правила экипировки и стеков.

- Поиск по отображаемому и исходному названию, несколько слов, без различения регистра и е/ё.
- Категории «Все», «Экипировка», «Припасы», «Прочее». Надетые предметы показываются отдельно.
- Сортировка по исходному порядку, названию или количеству. Сортируется представление, а не массив inventory: идентификаторы gearN остаются привязаны к исходным индексам.
- Названия предметов на ячейках, количество, счётчик заполненности и состояние отсутствия результатов. Поиск сбрасывается при смене объекта героя.
- Подтверждение выбрасывания одной вещи и подарка выбранному NPC. Отмена ничего не расходует; перед началом подхода и при передаче повторно проверяется исходный герой, состояние и содержимое рюкзака. Изменившийся список не приводит к передаче вещи с другим индексом.
- Запасные мечи и броня доступны для передачи, даже если первый экземпляр надет. Снять надетый предмет в полный рюкзак нельзя. Бой, движение, ожидание броска и бессознательное состояние блокируют действия с передачей/выбрасыванием.
- Действие с оружием открывает существующую настройку рук. Торговля, новая экономика, новые виды снаряжения и произвольные свойства найденной брони в это обновление не входят.

Источники: `src/inventory-rules.js` (чистые правила), `dist/inventory.js` (действия), `dist/views.js` (экран), `dist/inventory-ui.css` (адаптивная вёрстка). `dist/inventory-rules.js` генерируется сборкой.

Проверки: `tests/inventory-rules.mjs`, `tests/inventory-browser.cjs` (390×844, 844×390, 320×568), `tests/mobile-browser.cjs`, общий `tests/run-logic.mjs`. Скриншоты браузера хранятся вне репозитория. Физический iPhone и Android этим тестированием не подтверждены.
