## Запуск и проверки
Node.js 24 (тесты API используют node:sqlite).
```
npm ci
npm run build
node tests/inventory-rules.mjs
node tests/heroes-api.mjs
node tests/worlds-api.mjs
node tests/worlds-client.mjs
```
Для просмотра интерфейса можно раздать dist обычным HTTP сервером. Серверные /api требуют Cloudflare Worker и D1; статический сервер не заменяет backend. Данные героев/миров не входят в исходники.

## Где менять
- dist/index.html, dist/style.css: интерфейс. CSS содержит накопленные переопределения; сначала устранить конфликтующие правила.
- dist/game.js: движение, действия, бой, переходы, состояние.
- dist/views.js: герой, рюкзак, диалоги.
- dist/hud.js, dist/ui-icons.js, dist/artwork.js: HUD, SVG-иконки, иллюстрированные ассеты/портреты.
- dist/inventory.js, dist/torches.js: предметы, экипировка, факелы.
- src/voxel.js: исходник Three.js рендера, свет, модели, выбор объектов. dist/voxel.js генерируется, его вручную не менять.
- src/hero-rules.js, src/inventory-rules.js: общие правила, браузерные bundles генерируются.
- src/world-api.js, src/server.js и другие src/*api*: серверные обработчики; drizzle/: миграции.
- build.mjs: сборка браузерных модулей и Worker в dist/server, публикационный клиент dist/client.
- dist/assets/: изображения, шрифты. Не удалять как якобы неиспользуемые без проверки.

## Решения владельца
Приоритет — iPhone, вертикальный экран, всё по центру. Стиль иллюстрированный/умеренно пиксельный, без излишнего реализма. Иконки должны быть изображениями/SVG, не Unicode/emoji. Портрет отражает выбранную внешность героя.
Рюкзак: 20 ячеек; одинаковые расходники складываются; надетое/в руках и сюжетные записки не занимают ячейки. Перед выбрасыванием экипировку снимают вручную. Проверять вместимость и на клиенте, и на сервере.
Двери только в стенах. После перехода герой появляется возле соответствующей двери. NPC сохраняется в доступной игроку комнате после перехода. Предметы не перекрывают друг друга; источники света не отбрасывают собственную тень.
Диалоги и броски раздельны, не перекрывают основную игру огромными плашками. Портреты NPC согласованы на всех шагах.

## Реализовано / планы
Сейчас сценарная проба, не генеративный мир. ИИ-ведущий и мультиплеер не подключены.
Планы: один герой на игрока; мир/история привязываются к герою до завершения; приглашения позже, разница уровней не больше одного; после мира переносится только надетое и оружие в руках, остальные вещи/золото остаются. Новая проблема мира/процедурные локации и согласованные NPC — будущая работа. При выходе игрока в бою ИИ бережёт героя; обсуждены возврат и 30 секунд. Воскрешение погибшего товарищами допускается.
Не выдавать планы за реализованные механики.
